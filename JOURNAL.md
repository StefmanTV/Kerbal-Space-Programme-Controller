# November 24, 2026: Making of KSP Controller

I actually started working on this project almost a week ago. I made a prototype project mainly to understand how the software worked.
It didn't go really well so I started a new one. I am using Arduino Leonardo as all I need is to input things not output. At first I was
going to add a wheel to change between the different SAS modes, but I eventually got overwhelmed by that idea. I started by adding a "STAGE"
button(which was really easy) and then proceeded with the "MAP" button, which tbh was a little tricky. After that I added the SAS and RCS switches.
I want two joysticks, one to move the spaceship normally, while the other to move it using RCS. I made the RCS joystick to read x and y values only
then RCS switch is on. Later that day I made the time forward and backward buttons, which were an idea of my best friend. I worked for about an hour
yesterday at night and I made the throttle. I am using a slide potentiometer for this. To be honest, I had NO idea how to make it so I used AI to
make it. I didn't actually learn anything from it as I just copy-pasted it. The next day I felt bad about it so I deleted the AI code and made my
own. I asked some help from my friend with the map function on code.
